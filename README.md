# Scribbler

## 커맨드 시스템

vim 스타일의 커맨드 입력창으로 캔버스를 제어합니다.
`:`로 시작하면 커맨드, 그렇지 않으면 오브젝트 생성입니다.
러닝 커브가 높은 대신 익히고 나면 마우스 없이 모든 작업이 가능합니다.

좌표는 그리드 단위이며, 오브젝트는 생성 순서대로 36진수 ID(0, 1, ..., 9, a, b, ..., z, 10, 11, ..., 1z, ...)가 부여됩니다.
ID는 오브젝트 옆에 작게 표시됩니다.

### 좌표 / 범위 표기

| 표기           | 의미                           |
| -------------- | ------------------------------ |
| `@x,y`         | 단일 위치 (예: `@10,20`)       |
| `@x1,y1@x2,y2` | 직사각형 범위 (예: `@1,2@5,8`) |

---

### 커맨드 레퍼런스

| 커맨드                      | 전체 의미            | 설명                                                             |
| --------------------------- | -------------------- | ---------------------------------------------------------------- |
| **생성**                    |                      |                                                                  |
| `텍스트 @x,y`               |                      | 텍스트 오브젝트 생성                                             |
| `:l @x,y @x,y`              | **l**ine             | 선 생성                                                          |
| `:rect @x,y @x,y`           | **rect**angle        | 사각형 생성                                                      |
| `:rect <id>`                |                      | 텍스트에 사각형 보더 추가                                        |
| `:circ @x,y <반지름>`       | **circ**le           | 원 생성                                                          |
| `:circ <id>`                |                      | 텍스트에 원형 보더 추가                                          |
| `:img <경로\|url> @x,y`     | **img**              | 이미지 삽입                                                      |
| `:cn <id> <id>`             | **c**o**n**nect      | 두 오브젝트를 선으로 연결. 오브젝트 이동 시 선이 자동으로 따라옴 |
| `:cn <id> -> <id>`          |                      | 연결선에 화살표 추가                                             |
| **편집**                    |                      |                                                                  |
| `:d <id\|범위>`             | **d**elete           | 삭제                                                             |
| `:m <id\|범위> @x,y`        | **m**ove             | 이동. 범위는 화면 중앙 기준 절대 이동                            |
| `:r <id> <새 내용>`         | **r**eplace          | 텍스트 내용 교체                                                 |
| `:cp <id\|범위> @x,y`       | **c**o**p**y         | 복사하여 위치에 붙여넣기 (좌상단 기준)                           |
| `:grp <id> <id> ...`        | **gr**ou**p**        | 여러 오브젝트를 그룹으로 묶음. 그룹에 새 ID 부여                 |
| `:ungrp <id>`               | **un**-**gr**ou**p** | 그룹 해제                                                        |
| `:lock <id\|범위>`          | **lock**             | 오브젝트 잠금 (이동·삭제 방지)                                   |
| `:unlock <id\|범위>`        | **unlock**           | 잠금 해제                                                        |
| **레이어**                  |                      |                                                                  |
| `:top <id>`                 | **top**              | 맨 앞으로                                                        |
| `:bot <id>`                 | **bot**tom           | 맨 뒤로                                                          |
| `:up <id>`                  | **up**               | 한 단계 앞으로                                                   |
| `:dn <id>`                  | **d**ow**n**         | 한 단계 뒤로                                                     |
| **스타일**                  |                      |                                                                  |
| `:c <id\|범위> <색상>`      | **c**olor            | 색상 변경 (예: `:c 0 red`, `:c 1,1-5,5 #ff0000`)                 |
| `:s <id\|범위> <크기>`      | **s**ize             | 폰트 크기 변경                                                   |
| `:b <id\|범위>`             | **b**old             | 굵게 토글                                                        |
| `:i <id\|범위>`             | **i**talic           | 기울임 토글                                                      |
| `:u <id\|범위>`             | **u**nderline        | 밑줄 토글 (인수 있을 때)                                         |
| `:w <id\|범위> <굵기>`      | **w**idth            | 선·테두리 굵기 변경 (인수가 id+숫자일 때)                        |
| `:a <id\|범위> <0-100>`     | **a**lpha            | 투명도 설정                                                      |
| `:font <id\|범위> <폰트명>` | **font**             | 폰트 패밀리 변경                                                 |
| **검색**                    |                      |                                                                  |
| `/검색어`                   |                      | 캔버스 내 텍스트 검색. 일치하는 오브젝트 하이라이트              |
| **실행 취소**               |                      |                                                                  |
| `:u`                        | **u**ndo             | 실행 취소 (인수 없을 때)                                         |
| `:r`                        | **r**edo             | 다시 실행 (인수 없을 때)                                         |
| **파일**                    |                      |                                                                  |
| `:w` / `:w <이름>`          | **w**rite            | 저장 (인수 없을 때)                                              |
| `:wq`                       | **w**rite **q**uit   | 저장 후 종료                                                     |
| `:q`                        | **q**uit             | 종료 (미저장 시 경고)                                            |
| `:q!`                       | **q**uit!            | 강제 종료                                                        |
| `:e <이름>`                 | **e**dit             | 파일 열기                                                        |
| `:x [png\|svg\|jpg]`        | e**x**port           | 이미지로 내보내기                                                |
| **캔버스**                  |                      |                                                                  |
| `:z <퍼센트>`               | **z**oom             | 줌 설정 (예: `:z 150`)                                           |
| `:g`                        | **g**rid             | 그리드 표시 토글                                                 |
| `:0`                        |                      | 원점(0,0)으로 이동                                               |
| `:f`                        | **f**it              | 전체 콘텐츠가 화면에 맞게 조정                                   |
| `:pv`                       | **p**re**v**iew      | ID 라벨 숨김/표시 토글                                           |
| **강조**                    |                      |                                                                  |
| `:hl <id\|범위\|@x,y> [초]` | **h**igh**l**ight    | 지정 오브젝트나 위치를 일시적으로 강조. 기본 3초 후 자동 해제    |

> `:u`와 `:w`는 인수에 따라 동작이 달라집니다. `:u` 단독 → undo, `:u 0` → 오브젝트 0 밑줄 토글. `:w` 단독 → 저장, `:w 0 3` → 오브젝트 0의 선 굵기를 3으로.

## 기능 구현 현황

### 마우스 인터랙션

마우스와 커맨드 입력창은 서로 협력합니다. 마우스로 오브젝트를 선택하면 해당 ID가 입력창에 자동으로 채워지고, 이어서 커맨드를 타이핑해 작업을 완성할 수 있습니다.

- [x] 오브젝트 클릭 시 선택 상태가 되며, 해당 ID가 커맨드 입력창에 자동으로 채워집니다. (예: `0` 클릭 → 입력창에 `0` 입력 → `:d Enter`로 삭제)
- [x] 빈 공간 클릭 시 해당 그리드 좌표가 입력창에 `@x,y` 형태로 채워집니다. (텍스트 입력 흐름 자연스럽게 연결)
- [x] `Shift+클릭`으로 여러 오브젝트를 추가 선택할 수 있습니다. 범위로 변환되거나 ID 목록으로 입력창에 채워집니다.
- [ ] 빈 공간 드래그로 범위를 선택할 수 있습니다. 선택 완료 시 `x1,y1-x2,y2` 형태로 입력창에 채워집니다.
- [x] 선택된 오브젝트를 드래그하여 이동할 수 있습니다. (`:m`과 동일한 효과)
- [ ] 선택된 오브젝트 모서리의 핸들을 드래그하여 크기를 조절할 수 있습니다.
- [x] 오브젝트에 호버 시 ID 라벨이 강조되어 표시됩니다.
- [x] 오브젝트 더블클릭 시 텍스트 인라인 편집 모드로 진입합니다.
- [ ] 우클릭 시 해당 오브젝트에 적용 가능한 커맨드 목록이 컨텍스트 메뉴로 표시됩니다.
- [ ] `Space+드래그`로 캔버스를 패닝합니다.
- [x] 마우스 휠로 줌 인/아웃합니다. 줌은 커서 위치 기준으로 동작합니다.

### 원하는 위치에 글씨 쓰기

- [x] 원하는 위치에 글씨를 쓰도록 하기 위해서 화면에 그리드를 제공합니다.
- [x] 클릭한 위치에 텍스트 커서가 즉시 표시됩니다.
- [ ] 그리드 스냅(snap-to-grid) 기능을 켜고 끌 수 있습니다.
- [ ] 그리드 셀 크기를 조절할 수 있습니다.
- [x] 텍스트 블록을 드래그로 다른 위치로 이동할 수 있습니다.

### 글씨 색상, 크기, text-decoration 등 스타일 지정 가능

- [ ] 색상 선택 시 텍스트에 실시간으로 미리보기가 적용됩니다.
- [ ] 현재 적용된 스타일(색상, 크기, 굵기, 기울임, 밑줄)이 항상 표시됩니다.
- [ ] `Ctrl+B` 굵게, `Ctrl+I` 기울임, `Ctrl+U` 밑줄 단축키를 지원합니다.
- [ ] 최근 사용한 색상을 팔레트에 자동으로 표시합니다.
- [ ] 폰트 크기는 직접 입력과 +/- 버튼 두 가지 방식 모두 지원합니다.
- [ ] 폰트 패밀리를 변경할 수 있습니다.
- [ ] 투명도(alpha)를 0~100으로 조절할 수 있습니다.

### 도형 그리기 가능

- [ ] 사각형을 두 좌표로 생성할 수 있습니다.
- [ ] 원을 중심 좌표와 반지름으로 생성할 수 있습니다.
- [ ] 선 그리기 중 시작점에서 현재 마우스 위치까지 미리보기 선이 실시간으로 표시됩니다.
- [ ] `Shift` 키를 누른 상태에서 선 그리기 시 수평·수직·45° 방향으로 고정됩니다.
- [ ] 선·도형의 굵기, 색상, 스타일(실선·점선·화살표)을 선택할 수 있습니다.
- [ ] 완성된 도형을 클릭하면 선택 상태가 되어 수정하거나 삭제할 수 있습니다.
- [ ] `Escape` 키로 그리기를 중단할 수 있습니다.

### 오브젝트 연결 가능

- [ ] 두 오브젝트를 선으로 연결할 수 있습니다.
- [ ] 연결된 오브젝트가 이동하면 연결선이 자동으로 따라옵니다.
- [ ] 연결선에 화살표를 추가할 수 있습니다.
- [ ] 연결선도 색상·굵기 스타일을 변경할 수 있습니다.

### 오브젝트 편집 가능

- [ ] 오브젝트를 복사하여 다른 위치에 붙여넣을 수 있습니다.
- [ ] 여러 오브젝트를 그룹으로 묶어 함께 이동·삭제할 수 있습니다.
- [ ] 그룹을 해제할 수 있습니다.
- [ ] 오브젝트를 잠가 실수로 이동·삭제되는 것을 방지할 수 있습니다.
- [ ] 레이어 순서를 변경할 수 있습니다 (맨 앞·맨 뒤·한 단계).

### 이미지 삽입 가능

- [ ] 로컬 파일 또는 URL로 이미지를 캔버스에 삽입할 수 있습니다.
- [ ] 삽입된 이미지의 위치를 이동할 수 있습니다.
- [ ] 삽입된 이미지의 크기를 조절할 수 있습니다.

### 일시적 강조 가능

- [ ] 특정 오브젝트나 위치를 일시적으로 강조할 수 있습니다.
- [ ] 강조 효과는 지정한 시간(기본 3초) 후 자동으로 사라집니다.
- [ ] 강조 표시 중에도 다른 커맨드를 계속 입력할 수 있습니다.

### 캔버스 내 검색 가능

- [ ] 캔버스 내 텍스트를 검색하면 일치하는 오브젝트가 하이라이트됩니다.
- [ ] 다음·이전 검색 결과로 이동할 수 있습니다.
- [ ] 검색 결과가 없을 때 명확한 피드백을 제공합니다.

### 무한캔버스

- [ ] 현재 줌 레벨이 항상 표시됩니다.
- [ ] 마우스 휠로 줌, Space+드래그로 패닝이 가능합니다.
- [ ] 줌 인/아웃은 마우스 커서 위치를 기준으로 동작합니다.
- [ ] 원점으로 즉시 복귀하는 버튼 및 단축키를 제공합니다.
- [ ] 전체 콘텐츠가 화면에 맞게 자동 조정되는 "전체 보기" 기능을 제공합니다.
- [ ] 미니맵으로 전체 캔버스 대비 현재 위치를 파악할 수 있습니다.
- [ ] 뷰 위치를 키에 저장하고 즉시 복귀할 수 있습니다.

### 모든 작업을 키보드로 제어 가능

- [ ] `?` 키로 커맨드 레퍼런스 패널을 열고 닫을 수 있습니다.
- [ ] 커맨드 입력창에서 위·아래 화살표로 이전 커맨드 이력을 탐색할 수 있습니다.
- [ ] 매크로를 정의하고 실행하여 반복 작업을 자동화할 수 있습니다.
- [ ] ID 라벨을 숨기고 실제 출력물처럼 미리볼 수 있습니다.

### 작업 내역 저장 및 불러오기 가능

- [ ] 변경 발생 시 자동 저장이 실행됩니다.
- [ ] 현재 저장 상태(저장됨 / 저장 중 / 미저장)가 항상 표시됩니다.
- [ ] `Ctrl+S` 단축키로 즉시 저장이 가능합니다.
- [ ] 저장하지 않은 상태에서 페이지를 벗어나려 할 때 확인 메시지를 표시합니다.
- [ ] 파일 이름을 지정하고 변경할 수 있습니다.
- [ ] 여러 파일을 관리할 수 있는 파일 목록 뷰를 제공합니다.

### 작업 내역을 이미지로 저장 가능

- [ ] 저장 범위를 선택할 수 있습니다 (전체 캔버스 / 현재 뷰 / 선택 영역).
- [ ] 저장 포맷을 선택할 수 있습니다 (PNG, JPG, SVG).
- [ ] 배경 투명도를 설정할 수 있습니다 (투명 / 흰색 / 커스텀 색상).
- [ ] 이미지 배율을 선택하여 고해상도로 저장할 수 있습니다 (1×, 2×, 4×).
- [ ] 저장 완료 시 명확한 피드백을 제공합니다.
